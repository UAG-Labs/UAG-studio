# Plan: PLAN-108 - Release Hardening

**Status:** Draft
**Repo Scope:** `UAG-studio`

## Goal
Prepare Studio for production desktop release.

## Tasks
1. Add unit, integration, and UI tests for core workflows.
2. Add visual regression checks for main app states.
3. Add packaging/signing/update plan as appropriate.
4. Audit errors, accessibility, keyboard workflows, performance, and persistence.
5. Document user workflows and compatibility requirements.

## Success Criteria
1. Desktop app builds and packages.
2. Open/edit/save/compile/export workflows are tested.
3. Accessibility and keyboard basics pass.
4. Release notes identify compatible core/compiler/language versions.
